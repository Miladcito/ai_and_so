# ai_and_so

A small space for turning ideas into something useful.

## GitHub setup

Configure your Git identity once:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

Then clone this repository, make your changes, and push them to GitHub:

```bash
git clone https://github.com/your-username/ai_and_so.git
cd ai_and_so
git add .
git commit -m "Describe your change"
git push
```
